# Zaks.io

Zaks.io builds open-source infrastructure for teams shipping software with AI agents.

- [Splitch](https://github.com/zaks-io/splitch) evaluates feature flags at Cloudflare's edge and collects experiment data for humans and AI agents.
- [Agent Paste](https://github.com/zaks-io/agent-paste) publishes agent-built HTML to a stable URL from the CLI or over MCP.
- [Insecur](https://github.com/zaks-io/insecur) lets agents and CI use credentials at runtime without exposing them to prompts, logs, or files.
- [Skills](https://github.com/zaks-io/skills) contains shared workflows for agent-driven engineering.
